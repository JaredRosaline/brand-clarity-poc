# Brand Clarity

Brand Clarity is a web application designed to help entrepreneurs and small business owners establish a clear brand direction. Through a guided questionnaire, users receive personalized recommendations for their brand personality, color palette, typography, audience insights, and next steps for building a cohesive visual identity.

This project was developed as the semester-long capstone project for the University of Florida's Master of Mass Communication program (Web Design and Online Communication concentration).

# Project Purpose

Many entrepreneurs know they need a strong brand but struggle to define where to begin. Brand Clarity simplifies the branding process by guiding users through a short discovery questionnaire and generating personalized recommendations that can serve as the foundation for their visual identity.

The application demonstrates how thoughtful UX design and front-end development can transform a traditionally overwhelming process into an approachable user experience.

# User Flow

1. Visit the homepage.
2. Learn about the purpose of Brand Clarity.
3. Complete the Brand Discovery Questionnaire.
4. Submit responses.
5. Receive personalized branding recommendations.
6. Restart the questionnaire if desired.

# Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/JaredRosaline/brand-clarity-poc.git
```

Navigate to the project folder:

```bash
cd brand-clarity-poc
```

Open `index.html` in your preferred browser.

No additional dependencies or installation are required.
